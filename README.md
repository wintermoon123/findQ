# 找问卷 · 社会科学问卷与量表检索

> 让每一次研究，都从找到合适的工具开始。

面向心理学、社会学、社会工作等社会科学专业学生与研究者的问卷、量表与社会调查检索平台。网站收录 140 个常用量表与调查工具，覆盖自评量表、他评量表、访谈量表、人格测验与大型社会调查 5 大类型，可按学科、类型、适用人群与发布年代多维筛选，并提供收藏、对比与详情查阅功能，帮助研究者在选题与设计阶段快速定位合适的测量工具。

## 主要功能

- **关键词检索**：按量表名称、别名与标签快速查找
- **多维筛选**：学科领域、量表类型、适用人群、发布年代自由组合
- **灵活排序**：默认排序、最多收藏、最新发布、最早发布、按名称
- **我的收藏**：本地保存关注的量表，随时回看
- **问卷对比**：最多同时对比 3 个量表，横向比较题项、耗时、信效度等信息
- **详情查阅**：题目示例、信度效度、参考文献、官方获取渠道与版权说明

## 技术实现

纯静态站点，无构建依赖，原生 HTML / CSS / JavaScript 实现。数据以 JavaScript 数组形式内置于 `data.js`，收藏与对比状态通过 `localStorage` 本地持久化。可直接双击 `index.html` 打开，或部署至任意静态托管服务。
